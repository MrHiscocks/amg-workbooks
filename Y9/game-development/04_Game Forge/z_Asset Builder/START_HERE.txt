The complete source project and all original assets are included.

TO PREVIEW ON WINDOWS
1. Extract this entire ZIP.
2. Double-click Open_Preview_Windows.bat.
3. Requires Python 3. Your browser opens the local preview automatically.
Keep the command window open while using the preview.
On Mac or Linux, run: python3 preview_server.py

TO PUBLISH AND ENABLE AUTOMATIC UPDATES
Read README.md. Use a dedicated public GitHub repository and its included
.github/workflows/pages.yml workflow. Choose GitHub Actions in Pages settings.
Upload the whole source project, including assets and the hidden .github folder.
Do not upload the preview folder or node_modules; these are not needed by GitHub.

TO ADD ASSETS LATER
Upload PNG/OGG/WAV files to the appropriate assets category folder and commit.
The workflow rebuilds the catalogue and site. See README.md for optional tags
and import settings. No website-code changes are needed for new assets.

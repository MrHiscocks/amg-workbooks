# Approved design contract

Reference: approved Game Forge library, asset details and expanded basket mockups, 9 October 2026.

Navy shell (#0b263f), light blue workspace (#eff7fc), white cards, dark navy text (#102448), muted blue text (#52709a), gold buttons (#ffc431). No cream tint. Sidebar 250px; topbar 64px. Compact illustrated hero, not a landing page. Four desktop card columns, two when the package drawer is open; responsive two/one columns. Cards use actual production PNGs against a subtle transparency grid. Backgrounds use uncropped 2:1 previews. Gold active category and package buttons. Rounded 12px cards, 8px buttons, restrained shadows.

Typography: system sans serif, deliberate weights and sizes; heading 32px desktop/25px small screen, body 16px, controls 14px, metadata 13px. Icons: consistent Lucide 20px, 2px stroke, meaningful accessible labels.

Visible copy: LEVEL LAB / GAME FORGE; Choose your assets. Build your own story.; [live count] assets to mix, match and make your own.; Search assets, characters, places…; Theme; Environment; Movement; Clear filters; All assets; Select multiple; My package; Add to package; Import help.

Components: Shell, category navigation, filter toolbar, asset grid/cards, reusable media preview, modal detail, package drawer, import help. Native dialog for focus containment. Keyboard and touch interaction; no hover-only controls. Mobile navigation drawer and full-height basket. Background/strip previews are optional and respect reduced motion.

Intentional functional extensions: live counts rather than fixed screenshot counts; pagination for all 1,042 concepts; save/load selection; alternate exports in details so no existing file is lost; explicit bulk result count. Default featured order matches the reference's varied assets; name sorting is a real optional sort. Use existing Level Lab artwork without generating replacement sprites.

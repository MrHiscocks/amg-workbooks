Tally finds the story inside the data

First, you will turn a messy dataset into trustworthy evidence. Then you will use it to understand audience needs, trends and preferences.

Microsoft Excel · CSV data · formulas and functions · filters · charts

Fix missing, inconsistent and duplicated data. Organise the spreadsheet so that every later calculation is based on reliable information.

Link connects every page and every choice

You will build a functioning three-page website with suitable media, clear navigation, external links and a consistent visual system.

Adobe Dreamweaver CC · HTML · CSS · JavaScript · organised site folder

The pages should feel like one product. Consistent styles, working links and sensible structure matter as much as individual visual effects.

Sprite turns the message into a challenge

Your game must do more than move a character. It should communicate the client’s message through meaningful goals, feedback and progression.

GameMaker Studio 2 · GML · sprites · objects · rooms · events and scripts

Give the player a clear goal, responsive controls and useful feedback so they always understand what to do next.

SEQUENCE
13 combines count-controlled and condition-controlled iteration. It makes the choice between for and while explicit.
14 develops counters, accumulators, averages, highest values, sentinel loops and combined repetition.
15 assesses loop selection, tracing, debugging, modification, testing and independent programming.
16 is a separate homework workbook intended to take approximately 30 minutes.
17 is optional stretch work containing three larger games or simulations, carefully introduced extra techniques and the first IDLE Workspace.

CLASSROOM USE
1. Add the required HTML file to a Google Classroom assignment.
2. Pupils download the file and open it in Chrome or Edge.
3. No login or internet connection is required after downloading the file.
4. Support & examples is always available above Workbook progress.
5. Teaching workbooks contain five builds and one larger sixth challenge.
6. Every coding task includes three progressive hints and an extension.
7. Debug tasks are editable and runnable in compact Python environments.
8. Useful starter comments remain inside the editors, but repeated annotation panels have been removed.
9. The code editor supports font size, undo, redo, reset, running Python and downloading .py files.
10. Drag the horizontal separator between the editor and console to resize both areas.
11. Workbook progress counts written responses, answered objective questions, repaired debug code and builds explicitly marked complete. It reaches 100% only when all counted elements are complete.
12. Pupils must enter their name and display ID before saving the completed workbook.
13. Workbook 17 introduces IDLE through downloadable starter files. Pupils submit one completed .py file alongside the HTML workbook.
14. The assessment contains marking-engine metadata for a 40-mark rubric and Developing, Secure or Mastery outcomes. The teacher confirms the final outcome.

ARTWORK
Each workbook contains its matching transparent Unit 3 cover graphic and badge artwork. All required interface artwork is embedded so each HTML file works independently.

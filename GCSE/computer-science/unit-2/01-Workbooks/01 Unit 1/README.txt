CLASSROOM USE
1. Add the required HTML file to a Google Classroom assignment.
2. Pupils download the file, then open it in Chrome or Edge.
3. Each workbook runs entirely in the browser; it does not require a login.
4. Pupils should enter their name and student display ID before beginning. Both are required when the workbook is saved.
5. Every clean template opens on its Overview cover. Pupils then move between lesson pages using the sidebar or Previous/Next buttons; the page does not continuously scroll.
6. Support & examples is available from the button directly above Workbook progress. It contains key concepts, examples, common errors and misconception checks without revealing task answers.
7. Each teaching workbook contains six scenario-led coding tasks. Build 06 is a larger in-class challenge rather than homework.
8. Every coding task contains three progressive hints and an optional extension challenge.
9. Drag the horizontal grip between the code editor and console to resize the two areas. The grip also works with the Up and Down arrow keys when focused.
10. Every Debug Lab snippet has its own compact Run, Stop, Reset and Clear output controls.
11. 05-unit-1-homework.html is a separate summary workbook intended to take roughly 30 minutes. It contains retrieval, two editable debugging tasks, a short repair and a substantial online-order challenge.
12. 06-unit-1-challenge-lab.html is optional stretch work. It teaches the extra techniques needed for three larger coding projects and deliberately contains no quiz or debugging section.
13. Annotation support is reduced gradually. Early builds provide section comments and partial patterns; later builds require pupils to add their own purposeful comments.
14. “Mark complete” updates the pupil’s own task tracker. It is not a teacher certification or login-based record.
15. Pupils use “Save Workbook” to download a copy containing their identity details, written answers, Python code and task completion marks. The student display ID is used in the downloaded filename.
16. They should also download each .py program separately.
17. Pupils attach the completed HTML and .py files to the Classroom assignment.

BADGES
- Each workbook cover shows the badge available for completion.
- The standard workbook, homework and challenge badges remain pending until they are awarded through marking and feedback.
- The Unit 1 assessment contains a Core Checkpoint badge family. The marking outcome selects Developing, Secure or Mastery; the unmarked workbook does not claim an outcome.
- Stable badge and marking metadata is embedded in each HTML file for the future marking engine and student progress record.

IMPORTANT
Browser recovery is only a safety net on the same device and browser. Pupils should download their work before leaving a lesson.

This distribution is a clean template set. Embedded responses, completion marks and recovery data from earlier builds have been removed.

The files include the Python engine, editor and Python Lab artwork internally, so no companion folders or internet connection are required after download.

Building a Tkinter interface

A Tkinter program creates widgets, positions them and responds when the user interacts.

Structure

Window and main loop

Import Tkinter, create one main window and start the event loop last. mainloop() keeps the interface open and listening for events.

import tkinter as tk

window = tk.Tk()
window.title("Revision Helper")
window.geometry("420x260")

window.mainloop()
Widgets

Labels and entry boxes

A Label displays instructions or results. An Entry collects one line of text. Store each widget in a variable when you need to use it later.

promptLabel = tk.Label(window, text="Enter score:")
promptLabel.pack()

scoreEntry = tk.Entry(window)
scoreEntry.pack()
Events

Buttons and commands

A button uses command to name the function that should run when it is clicked. Do not add brackets after the function name.

def showMessage():
    print("Button clicked")

showButton = tk.Button(
    window, text="Show",
    command=showMessage
)
showButton.pack()
Data

Getting and updating values

Use .get() to retrieve text from an Entry. Cast it when a number is needed. Use .config() to change a label that already exists.

def calculate():
    score = int(scoreEntry.get())
    doubled = score * 2
    resultLabel.config(text=f"Result: {doubled}")
Layout

Layout managers

pack() places widgets in a simple sequence. grid() uses rows and columns for aligned forms. Use one layout manager within the same parent frame.

nameLabel.grid(row=0, column=0, padx=8, pady=8)
nameEntry.grid(row=0, column=1, padx=8, pady=8)
saveButton.grid(row=1, column=0, columnspan=2)
Validation

Useful validation feedback

Check entry text before processing it. Keep feedback inside the interface so the user knows what to correct.

def checkAge():
    text = ageEntry.get()
    if text.isdigit():
        resultLabel.config(text="Age accepted")
    else:
        resultLabel.config(text="Enter a whole number")
The essential event-driven pattern

Create widgets first, connect a button to a function, and place mainloop() at the very end. The function runs later, when the event occurs.

Button command fault

Success checks

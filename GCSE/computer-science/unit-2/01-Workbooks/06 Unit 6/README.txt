Classroom use
- Each HTML workbook is standalone and opens on Overview at 0%.
- Students must enter their name and display ID before Save Workbook works.
- The IDLE Workspace can download starter Python files directly.
- A copy of each starter is also supplied in the starter-files folder.
- For multi-file projects, students should keep files together and submit the development folder as a ZIP.
- Workbook 33 supports Developing, Secure and Mastery assessment outcomes. No outcome is awarded in the clean template.

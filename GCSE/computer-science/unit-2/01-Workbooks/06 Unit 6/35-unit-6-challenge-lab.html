02

Independent GUI toolkit

Use these focused patterns when the project brief requires them. Select techniques deliberately rather than adding widgets for decoration.

Feedback

messagebox feedback

Use messagebox for important confirmations, warnings or errors that require attention. Keep routine status information in normal labels.

from tkinter import messagebox

if name == "":
    messagebox.showerror(
        "Missing name",
        "Enter a player name."
    )
Navigation

Multiple frames

Create a frame for each major interface area. Use tkraise() to bring one frame to the front without creating a new main window.

pages = {}
for Page in (HomePage, RecordsPage):
    frame = Page(container)
    pages[Page] = frame
    frame.grid(row=0, column=0, sticky="nsew")

pages[HomePage].tkraise()
Widgets

ttk widgets

ttk provides themed widgets. Combobox supports controlled choices and Treeview can display record fields in columns.

from tkinter import ttk

activityBox = ttk.Combobox(
    window, values=["Running", "Cycling"],
    state="readonly"
)
activityBox.current(0)
Display

Treeview records

Define columns, headings and inserted values. Store the real records separately so the display can be rebuilt after edits.

table = ttk.Treeview(window, columns=("name", "score"), show="headings")
table.heading("name", text="Player")
table.heading("score", text="Score")
table.insert("", tk.END, values=("Alex", 18))
Files

Safe file-backed updates

Load records at startup, validate edits, update the in-memory collection, then rewrite the complete file. Confirm destructive changes.

def saveRecords():
    with open("records.txt", "w") as file:
        for record in records:
            file.write(f"{record['id']},{record['score']}\n")
Architecture

Project structure

Separate data access, validation, interface refresh and event functions. Test each function or workflow before adding the next feature.

loadRecords()
createInterface()
refreshTable()
window.mainloop()

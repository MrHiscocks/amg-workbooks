Classroom workflow
1. Distribute the required self-contained HTML workbook through Google Classroom.
2. Students enter their name and display ID before saving.
3. Short knowledge, tracing and debugging activities are completed in the workbook.
4. IDLE is the default practical environment. Students download the starter .py and supporting data files.
5. Students keep each project in a clearly named folder and use F5 to test in IDLE.
6. Students submit the saved HTML workbook plus the requested .py file or zipped project folder.
7. The assessment supports Developing, Secure and Mastery outcome badges.

Technical notes
- Workbooks are self-contained HTML files.
- Starter Python and data files download from inside each workbook.
- Student identity fields are excluded from progress calculations.
- Templates open on Overview and begin at 0%.
- Name and display ID are required before Save Workbook downloads a file.
- Embedded coding remains available for short inspection and debugging.
- Unit 5 uses the coral accent #FF6B57.

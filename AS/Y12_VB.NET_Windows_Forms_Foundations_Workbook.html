VB.NET Forms: from user input to useful output

This workbook focuses on the programming pattern you will use repeatedly in Windows Forms applications: declare variables, assign values from interface controls, process or calculate those values, then display the result.

TextBox input Variables Processing Labels & MessageBoxes Selection Iteration

Before you begin

By the end, you should be able to

Think in events

In a Forms application, code usually runs because something happens. Most of the examples in this workbook sit inside a button's Click event.

Typical pattern: the user enters data → clicks a button → your code runs → the form displays a result.
1 • Core programming workflow

Declare → assign → process → output

This is the main pattern to recognise and practise. Most small programs can be broken down into these four stages.

1
Declare variables
Create named storage locations with suitable data types.
2
Assign values
Read values from form controls and store them in variables.
3
Process
Use arithmetic, expressions, selection or loops to manipulate the data.
4
Output
Display the result using a label, textbox or message box.
Worked example • btnCalculate_Click
Private Sub btnCalculate_Click(sender As Object, e As EventArgs) Handles btnCalculate.Click ' 1. Declare variables Dim price As Double Dim quantity As Integer Dim total As Double ' 2. Assign values from the form price = Convert.ToDouble(txtPrice.Text) quantity = Convert.ToInt32(txtQuantity.Text) ' 3. Process total = price * quantity ' 4. Output lblTotal.Text = "Total: £" & total.ToString("0.00") End Sub

2 • Variables & values

Declaring and assigning variables

A variable stores a value while the program runs. Choosing the correct type makes code clearer and reduces errors.

Common data types

Integer whole numbers, e.g. 17

Double decimal numbers, e.g. 3.75

String text, e.g. "Cardiff"

Boolean True or False

Declaration and assignment

' Declare Dim score As Integer Dim name As String ' Assign score = 72 name = txtName.Text
Useful distinction: declaration creates the variable. Assignment puts a value into it. You can do both on one line, but you should understand them as separate ideas.

3 • Forms input & output

Working with interface controls

Forms applications usually get input from controls and send output back to controls.

Common inputs

txtName.Text → text from a TextBox

nudQuantity.Value → value from a NumericUpDown

chkMember.Checked → True or False from a CheckBox

cmbCourse.Text → selected text from a ComboBox

Common outputs

lblResult.Text = ...

txtOutput.Text = ...

MessageBox.Show(...)

lstResults.Items.Add(...)

Example: calculate a rectangle area

Private Sub btnArea_Click(sender As Object, e As EventArgs) Handles btnArea.Click Dim width As Double Dim height As Double Dim area As Double width = Convert.ToDouble(txtWidth.Text) height = Convert.ToDouble(txtHeight.Text) area = width * height lblArea.Text = area.ToString() End Sub

4 • Selection

Making decisions from form input

Selection lets a Forms application display different outputs depending on the data entered.

Example • grade classifier
Private Sub btnCheck_Click(sender As Object, e As EventArgs) Handles btnCheck.Click Dim mark As Integer mark = Convert.ToInt32(txtMark.Text) If mark >= 70 Then lblResult.Text = "Distinction" ElseIf mark >= 50 Then lblResult.Text = "Pass" Else lblResult.Text = "Not yet passed" End If End Sub

5 • Iteration

Repeating code in Forms applications

Loops can generate repeated output, process several values or keep checking a condition.

For loop

For i As Integer = 1 To 10 lstOutput.Items.Add(i) Next

This adds the numbers 1 to 10 to a ListBox.

While loop

Dim number As Integer = 1 While number <= 5 lstOutput.Items.Add(number) number += 1 End While

This continues while the condition remains true.

6 • Putting it together

One button, several programming constructs

The strongest habit is to keep your thinking structured, even as the program gets more complex.

Example • order calculator

Suggested interface

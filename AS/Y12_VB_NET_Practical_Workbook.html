Before you begin

  1. Open Visual Studio on Windows. Create a project using the Visual Basic Windows Forms App template your teacher uses. A .NET Framework version is also suitable for these examples. Do not select a C# or Console App template.
  2. Create a folder such as Y12_VB_Practicals in your school work area. Make a separate project for each numbered practical. Keep the full solution and project folders together.
  3. Open the form designer. Use View → Toolbox for controls and View → Properties Window (F4) for their properties. Select a control to edit it.
  4. The form code class may still be called Form1; keep your existing Public Class and End Class lines. Change a control’s (Name) before double-clicking a button to create its Click event. Press F5 to run and Shift+F5 to stop before editing.

Your programming habits

HabitWhat this looks like
Name it clearlyUse btnCalculate, txtMonthlySaving and lblResult, rather than Button1 or TextBox2.

Know where code belongsAn event runs after an action. Local variables go inside that event. Values needed across clicks go inside the form class, above the event procedures.

Worked example · btnAdd.Click

Inside the named event handler. Keep the existing Private Sub and End Sub lines.

' Declare variables for numeric input.
Dim firstNumber As Decimal
Dim secondNumber As Decimal
lblResult.Text = "Result appears here"

' TryParse assigns a number only when conversion succeeds.
If Not Decimal.TryParse(txtFirst.Text, firstNumber) Then
    MessageBox.Show("Enter a number in the first box.")
    txtFirst.Focus()
    Exit Sub
End If
If Not Decimal.TryParse(txtSecond.Text, secondNumber) Then
    MessageBox.Show("Enter a number in the second box.")
    txtSecond.Focus()
    Exit Sub
End If

' Process the numbers, then display the result.
Dim total As Decimal = firstNumber + secondNumber
lblResult.Text = total.ToString("0.##")
Why not just add the TextBoxes?

A TextBox contains a String. Convert to numeric values before arithmetic. TryParse returns True or False and avoids a conversion crash for an empty box or hello. 0.## displays up to two decimal places. The calculations in this practical use ordinary classroom-sized numbers.

  2. Use -, * and / for subtraction, multiplication and division.
  3. In Divide, reject a second number of zero before performing division.
  4. Write the Clear event yourself. Clear both inputs, reset the output and set focus.

Make matching explicit

Place Option Compare Binary at the very top of the form’s code file, before Public Class. This makes these String comparisons case-sensitive. Username spaces at the ends are trimmed. Password spaces are kept because they are part of the supplied password.

AndAlso needs both comparisons to be True. OrElse would allow someone in when only one detail is correct.

Types and scope

Type / scopeUse
StringNames, messages and other text.
IntegerWhole-number counts, months and marks.
DecimalMoney and decimal calculations; e.g. 0.045D.
BooleanTrue or False, such as whether a check passes.
Local variableDeclare inside an event for temporary work. A new local value is created each time the event runs.
Form-level variableDeclare inside Public Class, above events, when values must survive between clicks.

If something goes wrong

SymptomCheck this first
A control “is not declared”Compare its (Name) in Properties with your code. The displayed Text is not its code name.
Nothing happens when I clickCheck that the event has Handles btnName.Click and refers to the correct button.
A total resets on every clickMove only the values that need to persist to form level.
Invalid text crashes a calculationUse TryParse before processing, then check the permitted range.
The new mean includes old marksReset both the total and count when clearing the ListBox.
An error appears after pasting codeDo not nest one Private Sub inside another. Imports and Option statements belong above Public Class.
